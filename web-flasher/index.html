Releases and downloads
01

Connect your device

Connect the ESP to your computer using a USB data cable. Close any open serial monitor first.

02

Install firmware

Click “Connect device via USB”, select the USB port and choose “Install firmware”. If connecting fails: hold BOOT, briefly press RESET, release BOOT and try again.

03

Set up Wi-Fi and Jenkins

After restarting, the build light displays an LED code for its setup Wi-Fi network. Connect to that network and open the setup portal.

↻

Your next update needs no cable.

Open device administration and choose “Check for updates”. Select “Install update” to download the new firmware, verify it and restart the device.

When reinstalling via USB, settings are kept if the erase option stays unchecked. “Erase all device data” clears the flash before installation. “Erase device” clears the entire flash without installing anything; no firmware remains afterwards. Keep the cable connected while writing or erasing.
